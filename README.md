# 📋 To Do List App

Aplikasi To Do List sederhana dengan fitur autentikasi dan manajemen tugas.

## ✨ Fitur

- ✅ Login & Register dengan Email
- ✅ Reset Password dengan OTP via Email
- ✅ Manajemen Tugas (CRUD)
- ✅ Update Status Tugas
- ✅ Dashboard
- ✅ Responsive Design

## 🛠️ Teknologi

- Laravel 11
- PHP 8.2+
- MySQL
- HTML, CSS, JavaScript
- Font Awesome
- SweetAlert2
